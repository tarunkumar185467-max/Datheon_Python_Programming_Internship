# Datheon Python Programming Internship

Welcome to my Python Programming Internship project repository for Datheon.

This repository contains the Python projects I have completed as part of my internship tasks.

## Projects

### Task 1: Hangman Game
A terminal-based word guessing game built with Python. The player guesses the hidden word one letter at a time while keeping track of incorrect attempts.

**Features:**
- Random word selection
- Hidden word display
- Tracks guessed letters
- Limits incorrect attempts
- Displays win or loss messages

**File:** `Task1_Hangman/hangman.py`

### Task 2: Automatic File Organizer
A Python program that organizes files into folders according to their file extensions.

**Features:**
- Categorizes supported file types
- Preview mode before moving files
- Handles duplicate filenames
- Skips unknown file types and subfolders
- Displays a summary of file operations

**File:** `Task2_File_Organizer/organizer.py`
